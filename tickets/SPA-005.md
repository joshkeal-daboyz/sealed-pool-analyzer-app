# SPA-005: Parse ManaBox CSV, text, and collector-number pool files against one set

**Goal.** G-001 deliverable 4: "Parsers for ManaBox CSV exports (resolving by Scryfall ID, exact), plain text with counts, and collector-number lists, all resolving against one set only, reporting unresolved lines rather than guessing, and validating the pool against the kit template with a warning, not an error." Goal-level criterion 4 is completed by SPA-007, which adds the fixture pools and the test over all of them.

  - `core/src/main/kotlin/spa/core/cards/Pool.kt` (`Pool`, `PoolEntry`), if SPA-002 did not define them

  - Generating pool files or the fixture set (SPA-007).
  - Metrics (SPA-006) and the CLI (SPA-009).

The gate is `pipeline/gate/run.sh`; see the README's Toolchain section. A new or scratch file must also pass detekt's default rules.
- Resolution is always against one `CardIndex` (the target set plus its companions, from SPA-002). The index's exact lookups are the only lookups.
- A ManaBox CSV export has a header row. The known columns are `Name, Set code, Set name, Collector number, Foil, Rarity, Quantity, ManaBox ID, Scryfall ID, Purchase price, Misprint, Altered, Condition, Language, Purchase date, Purchase price currency`. Locate columns by header name, never by position; only `Scryfall ID` and `Quantity` are required. Real exports may add or drop columns. A real export from the 2026-11-06 event will replace the synthetic ones later; the parser must not depend on anything beyond the two required columns.
- `Pool` is a list of `PoolEntry(printing, count)`; `pool.cardCounts()` groups by `oracleId` and sums counts. `ParseResult(pool, unresolved, warnings, format, setCode)`.

## Acceptance criteria

1. `ManaBoxCsvParser.parse(text, index)` handles a UTF-8 byte-order mark, CRLF and LF line endings, quoted fields containing commas and doubled quotes, and columns in any order. Each row resolves by exact `Scryfall ID` to a printing in the index. A row whose id is unknown is an `UnresolvedLine(lineNumber, rawLine, reason)` with reason `wrong-set` when the row's `Set code` column is present and names a set outside the index, else `unknown-scryfall-id`. A row whose `Quantity` is not a positive integer is reason `bad-quantity`. A missing required column is a `PoolParseException` naming the column; blank lines are skipped and counted in `ParseResult.skippedLines`.
2. `TextListParser.parse(text, index)` accepts per line: `N Name`, `Nx Name`, `N x Name`, `Name xN`, `Name` (count 1), with an optional trailing `(SET) 123` or `[SET]` that is ignored. Names resolve through `index.byName`, so full `A // B` names and single face names both work. Resolution picks the printing of the target set with the lowest collector number (so counts attach to a printing); a card that exists only in a companion set resolves to that set's printing. A name that does not resolve is reason `unknown-name`. Lines starting with `#` or `//` are comments and skipped.
3. `CollectorListParser.parse(text, index)` accepts per line: `123`, `123 x2`, `2 123`, `2x 123`, `SET 123`, `SET 123 x2`, with collector numbers that may carry letters (`123a`, `7s`). No set means the target set. A set not in the index is reason `wrong-set`; a number not found in that set is reason `unknown-collector-number`.
4. `PoolParser.detect(text)` returns `MANABOX` when the first non-blank line contains `Scryfall ID`, `COLLECTOR` when at least 80 percent of non-blank, non-comment lines match the collector grammar, else `TEXT`. `PoolParser.parse(text, index, format = null)` uses the given format or the detected one and returns `ParseResult` with `format` set.
5. Unresolved lines never abort parsing and never resolve to a guess; `ParseResult.pool` holds exactly the resolved entries, and `unresolved` holds every other non-blank, non-comment line with its 1-based line number. Entries for the same printing on several lines are merged with summed counts.
6. `KitValidator.validate(pool, kitTemplate): List<KitWarning>` warns (never throws) when: the non-basic-land card count (or total count when `basicLandsSupplied` is false) differs from `boosters * cardsPerBooster + (1 if promo else 0)`; the rare-plus-mythic count is outside `[boosters - 1, boosters + 3]`; any single printing has a count above 4; the pool is empty. Each warning carries a code (`card-count`, `rare-count`, `high-count`, `empty`), the expected and actual values, and a sentence.
7. Unit tests against the `syn` index cover: a ManaBox file with BOM, CRLF, reordered columns, a quoted name with a comma, one unknown id, one wrong-set row, and one bad quantity; a text file with every count syntax, a full double-faced name, a front-face name, a comment, and two misspelled names; a collector file with every syntax, a companion-set line, a letter-suffixed number, a wrong-set line, and a missing number; detection for all three formats; merging of duplicate lines; each kit warning and a pool with no warnings.

## Change note

- Added `spa.core.intake` (the three parsers, `PoolParser.detect`/`parse`, `KitValidator`) and `spa.core.cards.Pool`/`PoolEntry`; the CSV reader is hand-written, no new dependency. `PoolParser.parse` takes an optional `kitTemplate` and fills `ParseResult.warnings` from it; the single-format parsers leave warnings empty.
- Additions the criteria needed but did not name: `ParseResult.resolvedLines` (so criterion 5 is testable), reason `unparsed` for a collector line that does not match the grammar, and `bad-quantity` for a zero count in text and collector files. `KitWarning.expected` is an `IntRange`; an empty pool returns only the `empty` warning; `high-count` applies to basic lands too, as written.
- Not done: no fuzzy matching, no lowercase-insensitive Scryfall ids beyond trimming. Collector numbers are tried exactly, then lowercased.
- For the next ticket: `.gitattributes` forces LF, so the CRLF case is built in the test from the LF resource (the BOM is real bytes in `manabox-mixed.csv`). `syn` has no companions, so companion and letter-suffix tests use a test-built `syn` + `sds` index with three test-only printings (`IntakeTestSupport.kt`).
