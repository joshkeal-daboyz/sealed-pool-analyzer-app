# SPA-004: Tag rules text, parse mana costs, and compute hypergeometric land math

**Goal.** G-001 deliverable 5, the string-only and arithmetic parts of the metric engine: "removal and interaction tags from rules-text patterns, fixing sources, ... hypergeometric land math". Pure functions over strings and integers, with no dependency on the card model, so this runs in parallel with SPA-002.

The gate is `pipeline/gate/run.sh`; see the README's Toolchain section. A new or scratch file must also pass detekt's default rules.
- `Color` is the enum `W, U, B, R, G` with a `fromSymbol(char)` helper, defined here in `spa.core.text`. SPA-002 has its own `Color` and an internal mana-cost reader in `spa.core.cards`. Do not use or change them. SPA-006 reconciles them onto this ticket's types.
- Patterns operate on Scryfall `oracle_text` and `type_line` strings. Oracle text uses `{W}` style symbols, the card's own name appears as its name, and reminder text is in parentheses.
- The tagger is a table of named regular expressions. The tests are the specification: every pattern has at least one real oracle text that hits it and one near-miss that does not.

## Acceptance criteria

1. `Tag` is the enum `REMOVAL, COUNTER, BOUNCE, TRICK, FIXING` with `isInteraction` true for `COUNTER`, `BOUNCE`, and `TRICK`. `RulesTagger.tag(typeLine, oracleText): Set<Tag>` is deterministic and ignores text inside parentheses.
2. `REMOVAL` is set when the text destroys, exiles, or deals damage to a target creature, target permanent, target creature or planeswalker, or "any target"; gives a target creature -N/-N with N >= 2 or "-X/-X"; has a creature "fight" or "bite" (deals damage equal to its power to target creature); or makes target creature's controller sacrifice it. It is not set for "destroy target artifact", "destroy target enchantment", damage only to players, or "-1/-1" alone. Each case has a test with a real card's text.
3. `COUNTER` is set for "counter target spell", "counter target creature spell", "counter target noncreature spell", and "counter target activated or triggered ability"; not for "can't be countered". `BOUNCE` is set for returning target creature, permanent, or nonland permanent to its owner's hand or putting it on top or bottom of its library; not for returning a card from a graveyard. `TRICK` is set when the type line is an instant and the text gives a target creature +N/+N or +N/+0, or when a card has flash and gives +N/+N; not for sorceries. Each case has a test.
4. `FIXING` is set when `ManaProduction.colors(typeLine, oracleText)` returns two or more colors or includes "any color"; `ManaProduction.colors` returns the set of colors a permanent can produce: from basic land types in the type line, from `Add {X}` patterns (including `Add {X} or {Y}`), from "Add one mana of any color" (all five), from "a land ... enters ... Add ..." text, and from text that creates one or more Treasure tokens (`create a Treasure token`, `create two Treasure tokens`, `create X Treasure tokens`), which returns all five colors. The Treasure rule matches the words outside parentheses, because a Treasure's mana ability appears only in reminder text, which criterion 1 ignores. A basic Forest returns `{G}`; a mono-color mana creature returns one color and is not `FIXING`; a Treasure maker is `FIXING`.
5. `ManaCost.parse("{2}{R}{R}")` returns `ManaCost(generic = 2, pips = {R: 2.0}, manaValue = 4)`. Hybrid `{G/W}` counts 0.5 toward each color and 1 toward mana value; Phyrexian `{W/P}` counts 1.0 toward its color; `{X}` adds 0 to mana value and sets `hasX`; `{C}` counts 1 generic; `{2/W}` counts 0.5 toward W, 2 toward mana value, and 0 toward `generic`. `generic` counts only `{N}` and `{C}` symbols. An empty or missing cost parses to all zeros. `coloredPipCount` is the sum of pips, `colors` the keys with weight > 0.
6. `Hypergeometric.atLeast(populationSize, successes, draws, k)` returns P(X >= k) exactly as a `Double`, with `pmf` beside it. Pinned values, each computed exactly from C(K,i)·C(N-K,n-i)/C(N,n): 40 cards, 17 lands, 7 drawn, at least 2 lands = 0.8948 (tolerance 0.0005); 40 cards, 17 lands, 7 drawn, at least 3 lands = 0.6493 (tolerance 0.0005); 40 cards, 8 sources, 9 drawn, at least 1 = 0.8974 (tolerance 0.0005); 40 cards, 0 successes, any draw, at least 1 = 0.
7. `LandMath.recommendLands(pips: Map<Color, Double>, totalLands = 17): Map<Color, Int>` splits lands in proportion to pips, rounds so the total equals `totalLands`, and gives every color with pips > 0 at least `minPerColor` (default 6) when two colors are present, taking the difference from the largest share. `LandMath.sourcesFor(targetProbability, cardsSeen, deckSize = 40): Int` returns the smallest number of sources whose `atLeast(deckSize, sources, cardsSeen, 1)` meets the target. Pinned: pips `{R: 20, G: 10}` gives `{R: 11, G: 6}`; pips `{W: 15, U: 15}` gives `{W: 9, U: 8}` or `{W: 8, U: 9}` deterministically by enum order; `sourcesFor(0.90, 9)` is 9 (8 sources give 0.8974, 9 give 0.9263); `sourcesFor(0.89, 9)` is 8 (7 sources give 0.8590).
8. Every public function has a KDoc stating its input conventions, and no function reads any file or environment.
