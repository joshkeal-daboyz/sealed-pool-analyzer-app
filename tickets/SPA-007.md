## Definitions

- Rarity pools over an index: `common` is every distinct card of rarity common that is not a basic land, drawn from the target set only; `uncommon`, `rare`, `mythic` likewise; `basicLand` is the target set's basic lands; `commonLand` is the target set's common nonbasic lands; `bonusSheet` is every distinct card of the companion sets. A slot draws a pool by its `weights` (normalized), then a card uniformly from that pool, then the printing of that card with the lowest collector number in its set. A booster never contains the same card twice; a slot that draws a duplicate redraws. The promo draws by its weights.
- Determinism: `KitSampler(index, kitTemplate).sample(seed): Pool` gives an identical pool for an identical seed, index, and template.

## Acceptance criteria

1. `KitSampler.sample(seed)` returns a pool of exactly `boosters * cardsPerBooster + (1 if promo)` entries by count, with every slot's `count` honored per booster, no duplicate card within a booster, basic lands only from the `basicLand` pool, and companion-set cards only from `bonusSheet`. Proven on the `syn` index and `fixtures/briefs/syn.json`.
2. The same seed gives an equal pool; seeds 1 and 2 give different pools; 200 kits with seeds 1 to 200 have rare-plus-mythic counts whose mean is within 10 percent of the template's expected value computed from the weights.
3. `PoolWriters.manaBox(pool)`, `text(pool)`, and `collector(pool)` produce files that `PoolParser.parse` (with the matching format) resolves to the same `cardCounts()` with zero unresolved lines. The ManaBox writer emits the full known header from SPA-005's background note, fills every column plausibly, and quotes names containing commas. The text writer uses `N Name` with full `A // B` names. Round-trip tests for all three on `syn` pools.
4. `./gradlew :core:generateFixtures` regenerates `fixtures/pools/` and `manifest.json` deterministically from seeds recorded in the manifest, so running it twice leaves the tree unchanged. The committed fixtures were produced by it, plus the hand edits in criterion 5.
5. `fixtures/pools/` holds at least 24 files: for `trk`, 10 ManaBox exports (`trk-manabox-01.csv` to `-10`), 5 text lists, 5 collector lists; for `syn`, 2 text lists that include at least one full double-faced name and one front-face-only name, and 1 collector list; and three hand-edited copies, `trk-text-misspelled-01.txt` with 3 misspelled names, `trk-manabox-wrong-set-01.csv` with 2 rows carrying a `trc` set code and Scryfall ids not in the index, and `trk-collector-bad-number-01.txt` with 2 numbers that do not exist. Every `trk` fixture uses the `trk` kit template, so some contain `sds` cards.
6. `manifest.json` lists every fixture with `file`, `set`, `format`, `seed` (or `null` for hand-edited), `expectedCards` (total count), and `expectedUnresolved` as a list of `{ line, reason }`. `FixturePoolsTest` parses every listed file with its declared set and format and asserts the total count and the exact unresolved lines, and fails if a file in `fixtures/pools/` is not in the manifest.
7. `fixtures/pools/README.md` says the pools are synthetic, how to regenerate them, that the ManaBox header is the best-known layout pending a real export from the 2026-11-06 event, and that replacing fixtures or the manifest is a ticket, not a side effect.

## Change note

- Added `spa.core.sim` (`RarityPools`, `KitSampler` with a `SampledKit` that keeps each card's kind and foil flag, `PoolWriters`, `FixtureManifest`, `FixtureGenerator` and its `main`), the `:core:generateFixtures` task, a `spa.pool.fixtures` test property, and 26 pool fixtures with `manifest.json` and `README.md`. The writers take optional extras beyond the one-argument forms: set names and foil counts for ManaBox, front-face-only cards for text.
- A duplicate redraws a card from the same kind, so each kind keeps its weight's chance; a kind with no card left is passed over, and a slot with nothing left throws. Redrawing the kind as well pushed `syn`'s 200-kit rare-plus-mythic mean to 10.15 against 8.24, because `syn`'s 8-card common sheet runs dry within a booster.
- Seeds were picked so that `trk-manabox-01.csv` and `trk-collector-05.txt` hold `sds` cards, and both `syn` text lists hold a full and a front-face-only double-faced name. `FixturePoolsTest` checks both. ManaBox ids, prices, and the purchase date are stand-ins.
- For SPA-008: `sds` bonus cards are mythic printings, so they count in a pool's rare-plus-mythic tally, while `expectedRaresAndMythics` counts only the rare and mythic weights (about 1 percent apart on `trk`). Changing `FixtureGenerator.plan` changes the base files of the three hand-edited copies, which must then be edited again by hand. Nothing here needs a device, the network, or a model.
