# SPA-011: Count booster basics correctly in the kit card-count warning

**Goal.** G-001 deliverable 4: "validating the pool against the kit template with a warning, not an error." SPA-005's criterion 6 made the card-count warning ignore basic lands when `basicLandsSupplied` is true. But a Play Booster's Land slot puts a basic in most boosters, so a real or sampled kit holds about 79 to 81 nonbasic cards plus 4 to 6 basics. Every sampled trk fixture is therefore warned as short of 85. This ticket corrects the rule before SPA-010 pins the `analyze` output.

## Definitions

- `kitTotal = boosters * cardsPerBooster + (1 if promo is not null else 0)`. It is 85 for both trk and syn.
- `boosterBasicSlots = boosters * (sum of count over slots whose weights include basicLand)`. It is 6 for both trk and syn.
- When `basicLandsSupplied` is true, the counted number is the pool's nonbasic cards, and the expected range is `[kitTotal - boosterBasicSlots, kitTotal]`, so 79 to 85 for trk and syn. Basic lands in the pool are not counted.
- When `basicLandsSupplied` is false, the counted number is all cards, and the expected range is `[kitTotal, kitTotal]`, as before.
- A `card-count` warning is raised when the counted number is outside the expected range. Its `expected` is that range, its `actual` is the counted number, and its message says which cards were counted.

## Acceptance criteria

1. `KitValidator.validate` implements the Definitions above for `card-count`. Unit tests use `fixtures/briefs/syn.json`'s template and cover, with basics supplied: 79 nonbasic plus 6 basics (no warning), 85 nonbasic plus 0 basics (no warning), 81 nonbasic plus 30 event basics (no warning), 78 nonbasic (warning, expected 79 to 85, actual 78), and 86 nonbasic (warning, actual 86). With a template copy whose `basicLandsSupplied` is false, they cover 85 total including basics (no warning) and 84 total (warning, expected 85 to 85, actual 84).
2. `FixturePoolsTest` asserts the card-count warnings for every fixture in `fixtures/pools/manifest.json`, parsed with its set's kit template. The 23 sampled fixtures have none. These three each have exactly one, with expected 79 to 85:
   - `trk-collector-bad-number-01.txt`, actual 76.
   - `trk-manabox-wrong-set-01.csv`, actual 78.
   - `trk-text-misspelled-01.txt`, actual 76.
   These values were computed by script from the fixture files, the Scryfall caches, and the Definitions. Every sampled fixture has 79 to 82 nonbasic cards and 3 to 6 basics, totaling 85.
3. The rare-count, high-count, and empty warnings behave as before: all existing `KitValidatorTest` cases for them pass unchanged.
4. `spa analyze` on `trk-manabox-01.csv` (80 nonbasic, 5 basics) prints `"kitWarnings": []`, and on `trk-text-misspelled-01.txt` prints one `card-count` warning with expected 79 to 85 and actual 76.
