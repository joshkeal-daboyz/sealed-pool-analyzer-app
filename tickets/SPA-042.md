# SPA-042: Tag each card's colour fixing and print a pool's fixing

**Goal.** G-005 deliverable 1 and criterion 5: class every card in a set's sealed pool as fixing or not, with the kinds of fixing and the colours it can supply, and add `spa fixing [<pool-file>] --set <code>`. The deck builder (SPA-044, SPA-045) uses this to build splash, three- and four-colour decks and to value fixing more when a deck needs it (owner, 2026-11-05).

## Scope

- Files or modules expected to change:

  - `cli/src/main/kotlin/spa/cli/`: the `fixing` command, wired in `Main.kt` and its help text, with tests
  - `README.md`: the command
- Not in scope:

## Background the Developer needs

- Read G-005: deliverable 1, criterion 5, and the Constraints, especially **easy to change how cards and decks are scored**.
- **The pool** is SPA-033's sealed pool, `GradingPool`: the set plus its companions, basic lands out, one card per oracle id. Sizes: `msh` 276, `hob` 188, `fra` 280, `trk` (with `sds`) 336.
- **Text.** Read every face's oracle text from `fixtures/scryfall/<code>/cards.json`. Remove reminder text first, meaning everything in parentheses. Treasure and basic landcycling reminder text would otherwise match the mana and search rules.
- **Rules.** A card gets a kind for each rule that matches any of its faces, and its colours are the union over its kinds:
  - **MANA**, for each `Add ...` clause, up to the next period or line end:
    - if the clause says `any color`, `any one color`, `any combination of colors` or `chosen color`, the colours are all five;
    - otherwise, if the clause names two or more different coloured symbols (`{W}` `{U}` `{B}` `{R}` `{G}`), the colours are those symbols.

    `{C}` and single-colour clauses do not count. Quoted abilities on tokens count too: trk's "New Planet" token makes Genesis Effect, Saurian Explorer and Gaseous Anomaly MANA, all five colours.
  - **CYCLING:** `Basic landcycling` gives all five colours. `Plainscycling`, `Islandcycling`, `Swampcycling`, `Mountaincycling` and `Forestcycling` give that land type's colour.
  - **SEARCH:** a `search your library for ...` clause, up to the next period or line end, that names a `land card` and does not say `into your graveyard`. All five colours.
  - **TREASURE:** a `create ... Treasure` clause in the same sentence. All five colours.
- **Alterable** (G-005 Constraints). Each kind is its own rule class behind one interface (for example `FixingRule { kind; colours(faceText) }`), in its own file. The classifier holds a list of rules. A new wording is a new rule, or a change to one rule, with no change to the classifier or the command.
- **Output.** `spa fixing --set <code>` prints every fixing card in the set's pool, sorted by name, one per line: name, kinds joined by `+`, colours in WUBRG order, and `land` when its front face is a land. The last line gives the count of fixing cards and the count for each kind. `spa fixing <pool-file> --set <code>` prints only the pool's fixing cards, with quantities. Its last line gives the copies and the copies that can supply each colour. Unknown set or unreadable pool: one line, exit 1.
- **Pinned numbers** come from an independent script (scratchpad `tools/fixing.js` and `tools/poolfixing.js`, 2026-11-05).
- Work on a local branch named exactly `SPA-042`. One Developer at a time. Never rewrite a pushed branch; keep scratch files out of the repository. JDK: README, Toolchain section.
