# SPA-030: Add Scryfall caches and blind format briefs for msh, hob, and fra

**Goal.** G-003 deliverable 5: the backtest needs the three past sets' card data and a format brief for each, so the Claude grader gets the same kind of input for them that it gets for `trk`. See the goal's Architect notes for why the sets are `msh`, `hob`, and `fra`.

## Scope

  - `fixtures/scryfall/msh/`, `fixtures/scryfall/hob/`, `fixtures/scryfall/fra/` (new), written by `spa fetch-set <code>` with `--companions` where the set has them

  - `fixtures/scryfall/README.md` and `fixtures/briefs/README.md`: one table row or line per set

## Background the Developer needs

- Install the CLI with `./gradlew :cli:installDist`; `README.md` documents `fetch-set` and `validate-brief`. Scryfall rate-limits at about 4 requests a second, and the fetcher already waits 500 ms (`tickets/lessons.md`, SPA-002).
- Companion sets: check each set's Scryfall data for cards that open in its Play Boosters from another set code (a bonus sheet, like `trk`'s `sds`). `fixtures/scryfall/trk/companions.json` shows the format. If a set has none, write `[]`.
- **The briefs must be blind.** Write each brief from Scryfall data alone: mechanics from the cards' rules and reminder text, each archetype's plan from that pair's gold uncommons and common themes, `speed` from the curve and keywords. Do not open 17Lands, set reviews, articles, or any win-rate or grade source, and do not write from memory of how the set played. The backtest measures a grade made without that knowledge.
- Follow `fixtures/briefs/README.md` and copy `trk.json`'s kit template unless the set's Scryfall data shows a different booster structure.
- **A pair with no gold cards (re-plan 1).** Some sets support fewer than ten pairs (`hob` has five factions: WU, RW, BR, BG, GU). The brief still needs ten archetypes, and they must not be invented. For a pair with no gold card and no dual land, write its `name` as `<Color>-<Color> (no designed archetype)`, a `plan` that says the set has no gold cards or dual lands for the pair and that a deck in these colors is built from each color's own cards, and as `signpostUncommons` one mono-color uncommon of each of the two colors, chosen from card text alone. Say in the change note which pairs got this treatment and why each signpost was picked. These are not designed signposts, and the plan says so. `hoc` (The Hobbit Eternal) is a separate product, not a companion; the folded seven-card Common slot is accepted where a set has no bonus sheet.
- Work on a local branch named exactly `SPA-030`. This PC runs one Developer at a time.

## Change note

Attempt 1 bounced because `hob` is a five-faction set: gold cards and dual lands exist only for WU (Humans), RW (Dwarves), BR (Goblins), BG (Wolves and Bears) and GU (Elves). Attempt 2 follows re-plan 1. Those five pairs get archetypes from their two gold uncommons, gold common and dual land. **WB, UB, UR, RG and GW** have no gold card at any rarity and no dual land, so each is named `<Color>-<Color> (no designed archetype)`, with a plan that says so. Their signposts are not designed signposts. The rule I used, from card text alone: one mono-color uncommon per color whose text needs no faction creature type and no faction mechanic (recruit, storied, amass, ferocious, landfall), so it works in a deck with no shared theme. I used a different card for each of a color's two placeholder pairs:

- WB: Stone by Sunlight (W, 2-mana instant that destroys a power 4+ creature or protects one) and Gnashing of Teeth (B, -5/-5 or -1/-1 sweep). Both are removal that works in any deck.
- UB: Old Fat Spider Can't See Me (U, Saga: hexproof, damage prevention, two cards) and Dreaded Bat-Cloud (B, 4/2 flying deathtouch, cheaper after a creature dies). Neither needs a creature type.
- UR: Ravenhill Flock (U, flyer that grows with each card drawn) and Burn, Burn, Tree and Fern (R, Saga: 6 damage to a creature, destroy an artifact, then mana).
- RG: Gandalf, Spark Starter (R, 4/3 reach that deals 3 damage divided on entry) and Troll Negotiations (G, two +1/+1 counters then fight).
- GW: Old Fat Spider (G, 6/7 reach that small creatures can't block) and Eagle of the Great Shelf (W, 2/5 flyer that grows with each other creature you control).

Scryfall caches for `msh`, `hob`, and `fra` from `spa fetch-set <code>` (no `--companions`; each `companions.json` is `[]`), and blind briefs `msh.json`, `hob.json` and `fra.json`. All three pass `spa validate-brief` with exit 0 and no warnings. Kit template: same as `trk.json`, except the "Common or bonus sheet" slot is folded into a seven-card Common slot, because none of the three sets has a bonus-sheet set. Companion check: Scryfall `/sets` lists these children: `msc`/`tmsh`/`amsh`, `hoc`/`thob`/`ahob`, `frc`/`pfra`/`tfra`/`afra`/`yfra`. None is a masterpiece or bonus sheet. `hoc` (The Hobbit Eternal, set type `eternal`) is the only unclear one. I read it as a separate product, not a bonus sheet, because it has commons and uncommons and 153 of its 158 cards are not Standard-legal. Scryfall's card `booster` flag is false for every card in all four sets (`trk` included), so it settles nothing.

Criterion 1: `cards.json` is a JSON array with one card per line plus the `[` and `]` lines, so the file has card count + 2 lines, the same as `trk` (583 for 581). `fra` holds 462 card objects against `card_count` 461. Scryfall's own `/sets/fra` says 461, and the extra object is the variant `101b` Compel Brutality.

Sources, for all three briefs: only the fetched Scryfall caches (`fixtures/scryfall/<code>/cards.json` and `set.json`) and Scryfall's `/sets` list and set and card search endpoints (for the companion check). Mechanics come from rules and reminder text, archetypes from each pair's gold uncommons and gold commons, and speed from the common and uncommon creature curve and keywords. For `hob`'s five placeholder pairs, the signposts come from the mono-color uncommons' rules text by the rule above. I used no 17Lands data, set reviews, articles, web searches, or memory of play.

Criteria 1 and 3 check. Run from the repository root with Python 3: `python check030.py msh hob fra`.

```python
import json, sys, collections
EVERGREEN = {"flying", "vigilance", "flash", "reach", "trample", "equip", "lifelink", "haste", "deathtouch", "enchant",
             "ward", "indestructible", "first strike", "menace", "double strike", "hexproof", "defender", "protection",
             "scry", "mill", "fight"}
for s in sys.argv[1:]:
    d = f"fixtures/scryfall/{s}/"
    st = json.load(open(d + "set.json", encoding="utf-8"))
    cards = json.load(open(d + "cards.json", encoding="utf-8"))
    lines = sum(1 for _ in open(d + "cards.json", encoding="utf-8"))
    print(f"{s}: card_count={st['card_count']} card_objects={len(cards)} file_lines={lines} "
          f"companions={json.load(open(d + 'companions.json'))}")
    try:
        b = json.load(open(f"fixtures/briefs/{s}.json", encoding="utf-8"))
    except FileNotFoundError:
        print(f"  {s}: no brief"); continue
    arch = b["archetypes"]
    print(f"  archetypes={len(arch)} pairs={sorted(''.join(sorted(a['colors'])) for a in arch)} "
          f"min_signposts={min(len(a['signpostUncommons']) for a in arch)}")
    names = {}
    for c in cards:
        names.setdefault(c["name"], c)
    kw = collections.Counter(k for c in names.values() for k in c.get("keywords", []))
    hay = " ".join((m["name"] + " " + m["rulesText"]).lower() for m in b["mechanics"])
    need = sorted(k for k, n in kw.items() if n >= 2 and k.lower() not in EVERGREEN)
    missing = [k for k in need if k.lower() not in hay]
    skipped = sorted(k for k, n in kw.items() if n >= 2 and k.lower() in EVERGREEN)
    print(f"  keywords on 2+ cards, not evergreen: {need}")
    print(f"  missing from mechanics: {missing or 'none'}")
    print(f"  left out as evergreen: {skipped}")
```

Evergreen keywords and keyword actions (flying through ward, plus scry, mill, fight) are left out of `mechanics` on purpose. They are core rules on every set's cards, and `trk.json` leaves them out too. A keyword counts as covered when its name appears in a mechanic's name or rules text, so "Cycling", "Typecycling", and "Landcycling" are covered by the Basic landcycling entry.
