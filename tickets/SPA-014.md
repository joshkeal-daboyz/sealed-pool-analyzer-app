# SPA-014: Match typed collector numbers regardless of letter case

**Goal.** G-002 deliverable 8: "a typed collector number matches a printing's number ignoring letter case, so `1701d`, `1701D`, `TRK 1701d`, and `trk 1701d` all resolve to `trk`'s `1701D`." Also goal criterion 17. This is the one `core` source change in G-002. It merges before any app ticket that shows collector-list results (SPA-016 onward), so the app is pinned to the fixed behaviour from the start.

## Scope

- Files or modules expected to change:
  - `core/src/main/kotlin/spa/core/cards/CardIndex.kt` (`byCollectorNumber` and the index it reads)
  - `core/src/main/kotlin/spa/core/intake/CollectorListParser.kt` (remove the lowercase retry, which becomes redundant)
  - `core/src/test/kotlin/spa/core/cards/CardIndexTest.kt`, `core/src/test/kotlin/spa/core/intake/CollectorListParserTest.kt`
  - `cli/src/test/kotlin/spa/cli/**`, only to add the test in criterion 5
- Not in scope:
  - Name lookup, the ManaBox and text parsers, fuzzy matching, and every other `core` behaviour.
  - Any file under `fixtures/`, `app/`, or `cli/src/main`.
  - The tagger's Guidance Failure BOUNCE gap, the other carried known issue (it changes goldens).
- Dependencies this ticket may add (none unless listed):
  - (none)

## Background the Developer needs

- JDK: if `java -version` does not report 21 in your shell, run `export JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-21.0.13.9-hotspot"; export PATH="$JAVA_HOME/bin:$PATH"` first. The gate is `pipeline/gate/run.sh`; see the README's Toolchain section. A new or scratch file must also pass detekt's default rules.
- The place of the fix is the Architect's choice (the goal leaves it open): `CardIndex.byCollectorNumber` matches ignoring case, by normalising the lookup key with `Locale.ROOT` both when the index is built and when it is queried. A printing's own `collectorNumber` keeps its printed case (`1701D`). `CollectorListParser` today tries the number as typed, then lowercased (`CollectorListParser.kt`, around line 51). That retry is removed, because the index now ignores case.
- Data, computed by script from the committed caches on 2026-11-03:
  - The only collector number with a letter in `trk`, `sds`, or `syn` is `trk` `1701D`, Captain Jean-Luc Picard (mythic, Scryfall ID `4d9fcb2a-b4fa-4990-861c-789926052104`).
  - Lowercasing creates no collision: `trk` has 581 printings and 581 distinct lowercase collector numbers, `sds` 30 and 30, `syn` 25 and 25.
  - No file in `fixtures/pools/` holds a letter-suffixed collector number in any case, so no golden file changes.
- Today, `spa analyze` on a one-line file holding `TRK 1701d` prints `"entries": 0` and one unresolved line, `{"line": 1, ..., "reason": "unknown-collector-number"}` (run by the Architect on 2026-11-03).

## Acceptance criteria

1. `CardIndex.byCollectorNumber` returns the printing whose `collectorNumber` is `1701D` for each of `("trk", "1701d")`, `("trk", "1701D")`, `("TRK", "1701d")`, and `("TRK", "1701D")`, and that printing's `collectorNumber` still reads `1701D`.
2. For a `trk` card index, a collector-number list holding exactly one line resolves to 1 entry, 1 card, the printing `1701D`, and 0 unresolved lines. One test case per line: `1701d`, `1701D`, `TRK 1701d`, and `trk 1701d`.
3. `trk-collector-bad-number-01.txt` still parses to 66 entries and 82 cards, with exactly two unresolved lines: line 2 (`TRK 777 x2`) and line 6 (`TRK 9001`), both with reason `unknown-collector-number`. These values are read from `fixtures/golden/trk-collector-bad-number-01.txt.json` and `fixtures/pools/manifest.json` in the test, not typed in.
4. For each of `trk`, `sds`, and `syn`, a unit test asserts that every printing is found by `byCollectorNumber` with its number uppercased and with it lowercased, and that the number of distinct lowercase collector numbers equals the number of printings.
5. A `cli` test runs `analyze` on a one-line pool `TRK 1701d` with `--set trk`, and asserts `"entries": 1`, an empty `unresolved`, and `totalCards` 1.
6. `./gradlew :cli:test` passes, and `git diff --exit-code 077e588 -- fixtures/golden` lists no changed file.
