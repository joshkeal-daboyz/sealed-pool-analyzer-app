# Lessons

What the Architect learned from merged tickets. One line each, newest first. Read before writing any ticket.

- 2026-11-04 SPA-019: A screen ticket that shows pool data must name how the screen receives it. SPA-019 put navigation out of scope, so Pair detail had no way to get the pool, and the Developer bounced before code. Before writing a screen ticket, trace the data from the ViewModel to the composable and scope each file on that path.
- 2026-11-04 SPA-020: `./gradlew --stop` stops every Gradle daemon on the PC, not just the caller's. The SPA-020 Inspector's stop killed the Acceptance Tester's connected test run. Tell the Test Inspector, when it runs beside the Acceptance Tester, to use `--no-daemon` for its runs and not to call `--stop`. A test that reads a file outside `fixtures/` must declare it as a task input (SPA-028).
- 2026-11-04 SPA-018: On spa-test, `adb shell input` taps and swipes do not move TalkBack focus, and TTS fails (error -4). A TalkBack criterion is checked by sending swipes through the emulator console (`adb emu event send`) and reading the focus ring in screenshots, not by speech. Pasted fixtures with misspellings get autocorrected word by word; open them through "Open file" instead where the criterion allows.
- 2026-11-04 SPA-017: Before pinning an outcome for a fixture read with a forced format, run `spa analyze --format <it>` on it. trk-collector-01 read as List with counts resolves 0 entries, so the spec gives a Not a pool card, not the Results header criterion 8 named.
- 2026-11-04 SPA-016: When the emulator types a pool with `adb shell input text`, the keyboard autocorrects card names (`Ortegas,` to `Ortega's,`). Device criteria that paste text should tell the tester to check the field against the file (uiautomator dump) before acting. A dispatch that names a local branch must use `SPA-###` in capitals, or the pre-push hook gates it as ticket `none`.
- 2026-11-04 SPA-027: Android compiles regexes with ICU, which rejects some patterns the JVM accepts (an unescaped `}`). RegexBraceGuardTest scans only `Regex("...")` and `.toRegex()` literals for that one case. A pattern built from a variable (`RulesTagger.rx`), passed to `Pattern.compile`, or held in a `const` is not scanned. A ticket that adds a regex in one of those forms should prove it on the device or extend the guard.
- 2026-11-04 SPA-016: The gate runs app code on the JVM, which has `java.*` methods Android lacks (`Files.readString`, at every API level). The first ticket that runs `core` on a device should prove it with an on-device test early. Don't infer an API's availability from `minSdk`; check it on the emulator.
- 2026-11-03 SPA-025: A wall-clock assertion in a unit test fails whenever the PC is busy, and parallel tester agents make it busy. A criterion that pins a duration names where it holds ("on CI"), and the test enforces it only there.
- 2026-11-03 SPA-013: Before a criterion names a third-party check, confirm it runs in the gate's environment. Compose's ATF checks run under Robolectric but skip every Compose node, which cost a re-plan. Name the property to check (48 dp, a label), not the tool.
- 2026-11-03 SPA-013: A ticket that changes a gate step should have a criterion that the step's `reproduce` command runs as printed. The Acceptance Tester found the ui-tests one missing `:app`, outside every criterion.
- 2026-11-03 SPA-012: A warning threshold is a statistical claim. Derive it from the generating distribution, and state its false-positive rate in the ticket. SPA-005's hand-picked rare range flagged one genuine kit in seven, and three of its four kit warnings needed fixing later.
- 2026-11-03 SPA-009: The command line was the first end-to-end run of the whole engine, and it surfaced a defect from three tickets earlier (SPA-005's kit warning). When a goal has an integration ticket, bring it as early as the dependencies allow, and have its Developer report anything odd in upstream output.
- 2026-11-03 SPA-009: A README sentence like "Errors are one line on stderr" is a contract too. Either make it an acceptance criterion or leave it out.
- 2026-11-03 SPA-008: Derive every pinned value from the actual template or data by script, not from what a flag's name suggests. `basicLandsSupplied` led to pinning 0 basics per kit, while the Land slot gives about 5. This is the second ticket bounced for a hand-derived pin (after SPA-004).
- 2026-11-03 SPA-007: Developers counted attempts differently (one counted an uncommitted red run, one didn't). For history, an attempt is a gate run on a commit the Developer pushes. Local runs before the first push are not attempts, but the Developer still names them in the change note.
- 2026-11-03 SPA-007: A statistical criterion should state the sample, the tolerance, and which cards count. The syn rare count sat at +8 percent against 10, and whether bonus-sheet mythics count was left open until the testers raised it.
- 2026-11-03 SPA-006: Before adding a criterion that says "existing tests pass unmodified", read what those tests assert. Criterion 8 forbade the only way to keep CardNormalizerTest's half-symbol cases passing, and the Architect had to rule on its own contradiction.
- 2026-11-03 SPA-006: The synthetic set lacks some cases (no BOUNCE card, no mana value 7 or more). A ticket whose rules depend on a tag or bucket should name a test case for each, rather than relying on the fixture set to happen to contain one.
- 2026-11-03 SPA-005: Say whether a lookup is case-insensitive in the criterion itself. Collector numbers were matched exactly then lowercased, so a typed `1701d` misses trk's `1701D`. Any later ticket that touches collector-number lookup should match case-insensitively.
- 2026-11-03 SPA-005: The first red gate in G-001 was detekt on new code. Developers fix it in one attempt, but it is the most likely first-push failure, so tickets can keep naming it in the background.
- 2026-11-03 SPA-003/SPA-004: When parallel tickets merge back to back, the second one's gate never ran with the first one's code. Run the gate on the combined tree (branch plus current main) before the second merge.
- 2026-11-03 SPA-004: Mana-production patterns came from a list in the criterion, so anything off the list is silently not fixing. "One mana of the chosen color" (Thriving lands) is the known gap. Before a set's metric ticket, grep the set's oracle text for every `Add` wording and list each one in the criterion.
- 2026-11-03 SPA-004: Compute every pinned number with a script before it goes into a ticket, and say in the criterion how it was computed. Two hand-computed probabilities were wrong, and the Developer had to bounce the ticket before writing any code.
- 2026-11-03 SPA-002/SPA-004: Two tickets running in parallel that both need a shared type will each define one. Give the type to exactly one ticket, and tell the other to leave it alone, or put the reconciliation into the first ticket that depends on both.
- 2026-11-03 SPA-002: For a rule that derives a field (layout rules), require a test case where the rule's answer differs from the obvious default. Otherwise a test can pass with the rule broken. The Inspector added three such tests.
- 2026-11-03 SPA-002: Scryfall rate-limited at about 4 requests a second in practice. The fetcher waits 500 ms, and live-fetch scenarios take a while.
- 2026-11-03 SPA-001: The gate does not find a JDK on its own, and sessions launched by the desktop app can predate the JDK install. Every ticket's background says how to set `JAVA_HOME` (README, Toolchain section).
- 2026-11-03 SPA-001: When one input drives two behaviours (ticket id `none` sets both the dependency rule and coverage threshold 0), give each behaviour its own test-plan row; the Inspector found the second one untested because the plan named only the resolver.
- 2026-11-03 SPA-001: The gate's `ui-tests` step fails once an `:app` project exists. The ticket that creates the app module must also implement that step, and say so in its scope.
- 2026-11-03 SPA-001: detekt runs its default rules on every new file, scratch files included. Criteria that say "add a scratch file" should expect it to pass lint, or the scenario fails at the wrong step.
