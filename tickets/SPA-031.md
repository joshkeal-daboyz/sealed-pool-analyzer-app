# SPA-031: Derive per-card win-rate grade tables from 17Lands game data

**Goal.** G-003 deliverable 4 and criterion 8: a per-card game-in-hand win rate (GIH WR) for each backtest set, mapped onto the grade scale, committed as a small table; the raw download is never committed.

## Scope

- Files or modules expected to change:
  - `agent/src/main/kotlin/spa/agent/winrate/**` and tests (new)
  - `cli/src/main/kotlin/spa/cli/`: a `winrates` command (`spa winrates <game-data.csv.gz> --set <code>`) that writes `fixtures/winrates/<code>.json`, wired in `Main.kt` and its help text; `cli/build.gradle.kts` adds `project(":agent")`
  - `fixtures/winrates/msh.json`, `hob.json`, `fra.json` and a `fixtures/winrates/README.md` (new)

  - `agent/src/main/resources/spa/agent/grades.schema.json` and `GradeEntry` in `agent/src/main/kotlin/spa/agent/grade/` (re-plan 1): two optional per-card fields, `gihwr` (number, 0 to 1) and `games` (integer, at least 0), with SPA-029's tests still passing and a test that a file with them round-trips and one with `gihwr` 1.5 fails

## Background the Developer needs

- Data: `https://17lands-public.s3.amazonaws.com/analysis_data/game_data/game_data_public.<SET>.PremierDraft.csv.gz` for `MSH`, `HOB`, `FRA` (22 to 31 MB each). One row per game. For each card there are columns `opening_hand_<name>`, `drawn_<name>`, `deck_<name>` and others, and `won` is the game result. Column names with commas are quoted.
- **GIH WR** of a card = among games where `opening_hand_<name> + drawn_<name> >= 1`, the share with `won` true. **Games** = the count of those games. This is 17Lands' "ever drawn" win rate.
- **Mapping to the scale** (Architect-derived, deterministic): over the set's cards with at least 500 games, take the mean `m` and the population standard deviation `s` of GIH WR. A card's `score` = `2.5 + (gihwr - m) / s`, clamped to [0, 5] and rounded to the nearest 0.5. `confidence` = `games / (games + 2000)`, rounded to 3 places. A card under 500 games gets no grade. `source` is `WIN_RATE`, and `provenance` names the file and its `Last-Modified` date.
- Match 17Lands names to `CardIndex` cards for the set (double-faced cards appear under their front face name in 17Lands; check the data and say in the change note what you found). A name that matches no card is listed in the command's output and skipped.
- **No 17Lands website endpoint (re-plan 1).** Use only the public game data files. `card_ratings/data` now returns a tiny recent window, and `/api/card_data` carries a notice that its data is only for use on 17Lands.com. Neither is used, for checking or anything else.
- Work on a local branch named exactly `SPA-031`. This PC runs one Developer at a time.

## Acceptance criteria

1. On a small committed test CSV (written by hand, about 10 games and 3 cards, one with a comma in its name), the parser computes GIH WR and games exactly as defined above, including a card that is only in the opening hand and one that is in the deck but never drawn (not counted).
2. The mapping gives the pinned scores for a hand-computed case (cards at `m`, `m + s`, `m - 3s`, `m + 0.74s`, and one under 500 games), with the arithmetic shown in the test.
3. `fixtures/winrates/<code>.json` for `msh`, `hob` and `fra` load through SPA-029's grade file loader (schema-valid, `source` `WIN_RATE`).
4. For five cards per set picked by the Acceptance Tester, the table's GIH WR and games (kept in the file as optional per-card fields `gihwr` and `games`) equal the values the Acceptance Tester recomputes from the same public game data file with a script of its own, written from the definition in Background without reading this ticket's code (GIH WR within 0.05 percentage points, games exact). (Re-plan 1: 17Lands' card ratings endpoint no longer gives full-window numbers, and the endpoint that does is marked for use on 17Lands.com only, so no check uses either.)
5. `spa winrates` lists unmatched names and exits 0; on a missing file it prints one line and exits 1.
6. No file over 1 MB and no `.csv.gz` is added (`git diff origin/main --stat`). The gate is green.

## Change note

- `spa.agent.winrate` reads 17Lands game data (own RFC 4180 reader, gzip by magic bytes), counts a card in a game when `opening_hand + drawn >= 1` (`tutored` ignored), and maps GIH WR with the ticket's formula; `spa winrates` writes `<data>/winrates/<code>.json`. `GradeEntry` and the schema gain optional `gihwr` (stored to 6 places) and `games`; null fields are not written, so existing grade files are unchanged.
- `m` and `s` are over the matched cards with 500+ games; unmatched names are listed and skipped. msh: 377,514 games, 58 unmatched, 278 graded, m 0.5620, s 0.0391. hob: 323,114, 0, 184, 0.5587, 0.0379. fra: 297,964, 10 unmatched (5 of them with 500+ games), 271 graded, 0.5593, 0.0390. Double-faced cards appear in 17Lands under their front face; `CardIndex.byName` finds them and the grade carries the full Scryfall name.
- Added `--dataset-date <yyyy-mm-dd>` (default: the file's modified date) because the command cannot see the HTTP `Last-Modified` header; the tables were built with each download's header date (msh 2026-07-27, hob 2026-10-01, fra 2026-10-19). A card is graded under the main set's first printing of it.
- Not unit tested: the run on the real downloads (not committed, needs the network). Criterion 4 is the Acceptance Tester's; my own spot check of two hob cards with a separate script matched exactly.
