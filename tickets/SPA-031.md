# SPA-031: Derive per-card win-rate grade tables from 17Lands game data

**Goal.** G-003 deliverable 4 and criterion 8: a per-card game-in-hand win rate (GIH WR) for each backtest set, mapped onto the grade scale, committed as a small table; the raw download is never committed.

## Background the Developer needs

- Data: `https://17lands-public.s3.amazonaws.com/analysis_data/game_data/game_data_public.<SET>.PremierDraft.csv.gz` for `MSH`, `HOB`, `FRA` (22 to 31 MB each). One row per game. For each card there are columns `opening_hand_<name>`, `drawn_<name>`, `deck_<name>` and others, and `won` is the game result. Column names with commas are quoted.
- **GIH WR** of a card = among games where `opening_hand_<name> + drawn_<name> >= 1`, the share with `won` true. **Games** = the count of those games. This is 17Lands' "ever drawn" win rate.
- **Mapping to the scale** (Architect-derived, deterministic): over the set's cards with at least 500 games, take the mean `m` and the population standard deviation `s` of GIH WR. A card's `score` = `2.5 + (gihwr - m) / s`, clamped to [0, 5] and rounded to the nearest 0.5. `confidence` = `games / (games + 2000)`, rounded to 3 places. A card under 500 games gets no grade. `source` is `WIN_RATE`, and `provenance` names the file and its `Last-Modified` date.
- Match 17Lands names to `CardIndex` cards for the set (double-faced cards appear under their front face name in 17Lands; check the data and say in the change note what you found). A name that matches no card is listed in the command's output and skipped.
- Check against 17Lands' card ratings: `https://www.17lands.com/card_ratings/data?expansion=<SET>&format=PremierDraft` returns `ever_drawn_win_rate` and `ever_drawn_game_count` per card for the whole format window.
- Work on a local branch named exactly `SPA-031`. This PC runs one Developer at a time.

## Acceptance criteria

1. On a small committed test CSV (written by hand, about 10 games and 3 cards, one with a comma in its name), the parser computes GIH WR and games exactly as defined above, including a card that is only in the opening hand and one that is in the deck but never drawn (not counted).
2. The mapping gives the pinned scores for a hand-computed case (cards at `m`, `m + s`, `m - 3s`, `m + 0.74s`, and one under 500 games), with the arithmetic shown in the test.
3. `fixtures/winrates/<code>.json` for `msh`, `hob` and `fra` load through SPA-029's grade file loader (schema-valid, `source` `WIN_RATE`).
4. For five cards per set picked by the Acceptance Tester, the table's GIH WR (kept in the file as an extra per-card field `gihwr`, with `games`) matches 17Lands' card ratings `ever_drawn_win_rate` within 0.5 percentage points. The Developer reports the same comparison for every card with at least 500 games (count within 0.5 points, and the worst case) in the change note.
5. `spa winrates` lists unmatched names and exits 0; on a missing file it prints one line and exits 1.
6. No file over 1 MB and no `.csv.gz` is added (`git diff origin/main --stat`). The gate is green.
