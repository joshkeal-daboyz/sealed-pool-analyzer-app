# SPA-035: Tag each card's themes and count them across a set

**Goal.** G-004 layer 2, deliverable 1 and criterion 3: deterministic theme tags for every card in a set's sealed pool, and counts of each theme across the set by colour and rarity, printed by `spa themes <set>`. Later tickets put these counts in the grading packet (SPA-036) and use them for pool synergy (SPA-038).

## Scope

- Files or modules expected to change:
  - `agent/src/main/kotlin/spa/agent/themes/**` and tests (new)
  - `cli/src/main/kotlin/spa/cli/`: `spa themes <code> [--data <dir>]`, wired in `Main.kt` and its help text, with tests
  - `README.md`: the command
- Not in scope:
  - `core` (its card model has no keywords; read them from the cache file, see Background). The grading packet, any grade, any model call.
- Dependencies this ticket may add (none unless listed):
  - (none)

## Background the Developer needs

- Read G-004 (layer 2, deliverable 1, criterion 3, Constraints, Architect notes).
- **The pool** is SPA-033's sealed pool: `GradingPool` (set plus companions, basic lands out, one card per oracle id).
- **Keywords:** `core`'s `Card` has none. Read each card's `keywords` array from `fixtures/scryfall/<code>/cards.json` (and each companion's) by `oracle_id`, using kotlinx-serialization's `JsonElement`.
- **Themes** (Architect-derived, fixed for this ticket):
  - A **keyword theme** is a keyword in a card's Scryfall `keywords`, unless it is evergreen. Evergreen means: Deathtouch, Defender, Double strike, Enchant, Equip, First strike, Flash, Flying, Haste, Hexproof, Indestructible, Lifelink, Menace, Protection, Reach, Trample, Vigilance, Ward, Scry, Mill, Fight. A keyword named in the set's format brief `mechanics` is always a theme, even if it is on that list.
  - A **type theme** is any subtype on any face's type line (the words after the dash), for example Spacecraft, Human, Equipment, Saga.
  - A card **has** a keyword theme when the keyword is in its `keywords`; it **has** a type theme when the subtype is on its type line.
  - A card **refers to** a theme when its rules text, after removing reminder text (anything in parentheses), the card's own face names, and every phrase `this <theme>`, contains the theme's name as a whole word (case-insensitive, an optional plural `s`), and the card does not have it as a keyword.
  - A theme is kept when at least 3 cards of the pool have it or refer to it.
- **Counts per theme:** cards that have it, cards that refer to it, cards that do either; each also split by colour (W, U, B, R, G, multicoloured, colourless, from `Card.colors`) and by rarity (C, U, R, M).
- **Output** of `spa themes`: one line per kept theme, sorted by the "either" count, highest first: name, kind (`keyword` or `type`), has, refers, either, then the colour and rarity splits. Exit 0. An unknown set prints one line and exits 1.
- Work on a local branch named exactly `SPA-035`. One Developer at a time. Never rewrite a pushed branch; keep scratch files out of the repository.

## Acceptance criteria

1. For a small hand-built set in tests: keyword, type and evergreen cases, a brief mechanic on the evergreen list kept, the reminder-text, own-name and `this <theme>` exclusions, the plural, the 3-card threshold, and the colour and rarity splits all give the expected tags and counts.
2. On `trk` (with `sds`), 336 pool cards, the counts equal these, computed by an independent script (G-004 Architect notes): Station has 17, refers 1; Surveil has 22, refers 0; Spacecraft has 17, refers 11; Human has 68, refers 1; Equipment has 4, refers 3. A test pins them.
3. `spa themes trk` prints the kept themes in the stated order and format and exits 0; an unknown set exits 1 with one line.
4. `git diff <G-004 start> -- core/src/main fixtures/golden` lists no file. The gate is green.

## Change note

- Added `spa.agent.themes` (`ThemeRules`, `SetThemes`, `Tally`, `ThemeCount`, `PoolThemes`) and `spa themes <code> [--data <dir>]`. Keywords come from each cached `cards.json` by oracle id through `ScryfallCache.load`'s `JsonObject`s; `core` is unchanged. Criterion 2's five themes match the script exactly on the first run; `trk` keeps 54 themes.
- Each line prints the either count's colour and rarity splits only (`colour W= U= B= R= G= M= C= rarity C= U= R= M=`); the has and refers splits are in `ThemeCount` for SPA-036. Ties sort by name. Name removal is a plain case-insensitive substring removal, longest name first; "does not have it as a keyword" compares the theme's name with the card's keywords for both kinds. A card of special or bonus rarity counts in totals and colours, not in the rarity split.
- A set with no brief has no mechanics (evergreen keywords stay out); an invalid brief is one line and exit 1. The criterion 2 test lives in `cli`'s tests, because only `cli`'s test task has the fixtures path.
- After the red commit, test cards named "A", "B" and "C" were renamed (removing a one-letter own name strips that letter from the text), and the test helper lost its `back` parameter and one long test was split in two, for detekt. No expectation changed.
