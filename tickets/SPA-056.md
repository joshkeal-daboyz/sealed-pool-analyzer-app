# SPA-056: A card names itself by its shortened legendary name too

**Goal.** The owner's rule (2026-11-05): shortened names "always start with the first word in the card name and end with the last word", "only relate to legendary creatures", and exclude the part of the name after a comma. SPA-051's self-reference facts (`enters-trigger`, `dies-trigger`, self-granted keywords) recognise only "this <type>", the full name and the name up to the first comma. So "When Captain Kirk enters" on Captain James T. Kirk gives no `enters-trigger`. This ticket adds the shortened form, and "<self> or another …" for enters triggers.

## Background the Developer needs

- Read SPA-051 (the fact rules) and G-005's Architect notes on the owner's examples.
- **Self names.** A card refers to itself by any of:
  - "this creature", "this permanent", "this artifact", "this enchantment", "this land", "this Spacecraft" or "this Vehicle", as each rule already allows;
  - its full name;
  - its name up to the first comma;
  - **for a legendary card only**, the first word and the last word of its name up to the first comma, joined by one space, when that part has three or more words. For example, "Captain Kirk" for Captain James T. Kirk, "Dr. McCoy" for Dr. Leonard "Bones" McCoy, and "Commander Musiker" for Commander Raffi Musiker.
- **Enters triggers** also match "When(ever) <self> or another … enters", for example Captain Kathryn Janeway's "Whenever Captain Janeway or another creature you control enters".
- **Pinned numbers** come from the Architect's script (scratchpad `tools/facts2.js`, 2026-11-05). The owner asked for no Fable work on the older sets; their fact counts move only because the rule is code.
- Work on a local branch named exactly `SPA-056`. One Developer at a time. Never rewrite a pushed branch; keep scratch files out of the repository. JDK: README, Toolchain section. On Windows Git Bash, pass `C:/...` paths to the JVM.
