# SPA-058: Freeze the trk otags tests, then commit the trk Fable cares file

**Goal.** G-005 deliverable 7, the cares tags. SPA-055 made `spa` merge `fixtures/otags/<code>.fable.json` into a set's cares by default. The Architect ran the Fable cares pass on trk and holds the result, but two existing tests pin trk as having no Fable file, so committing it turns the gate red. This ticket points those tests at a frozen copy of the trk otags, adds tests that pin the Fable file itself, and commits the file.

## Scope

- Files or modules expected to change:
  - `cli/src/test/kotlin/spa/cli/CaresScoringTest.kt` and `OtagsFixturesTest.kt` (the two failing tests only), and any other test that fails only because the Fable file exists
  - `fixtures/otags/v1/trk.json` (new, a byte copy of `fixtures/otags/trk.json`) and `fixtures/otags/trk.fable.json` (new, copied byte for byte)
  - a new test for the Fable file, in `cli/src/test/kotlin/spa/cli/`
  - `fixtures/otags/README.md`: one paragraph naming the two new files
- Not in scope:
  - Any main source file, `core`, `cares.json`, any tag, grade, weights or check file, any other otags file. No expected value in a moved test changes.
- Dependencies this ticket may add (none unless listed):
  - (none)
