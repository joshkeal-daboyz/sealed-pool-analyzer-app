# SPA-059: Freeze the msh, hob and fra otags tests, then commit their Fable cares files

**Goal.** G-005 deliverable 7 and the backtest (SPA-046), which scores `msh`, `hob` and `fra` with the cares tags. SPA-058 did this for `trk`: it froze the tests that pinned `trk` as having no Fable file and committed `fixtures/otags/trk.fable.json`. The Architect has now run the same Fable cares pass on `msh`, `hob` and `fra` and holds the three results. This ticket repeats SPA-058's steps for those three sets.
