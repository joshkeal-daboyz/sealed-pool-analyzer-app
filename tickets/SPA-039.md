# SPA-039: Measure the deck-pick test and tune the adjustment weights

**Goal.** G-004 deliverable 4 and criterion 6: `spa deck-pick` on 17Lands Sealed data, weights tuned on `msh` and `hob`, frozen, and measured on `fra`.

The Architect completes this ticket before dispatch, after SPA-038 merges. Outline:

- For each build by a player with `user_game_win_rate_bucket` 0.60 or more (Decided 2): pool = deck plus sideboard, basics out; candidates = pool cards castable in `main_colors`; N = the deck's nonbasic card count; overlap = share of the top N by a ranking that are in the deck.
- Rankings: random (seeded, averaged), set grade (best available version), adjusted grade.
- Tuning: a grid over the weight file on `msh` and `hob` only; the best is committed as `fixtures/weights/tuned.json`, then measured on `fra` once.
- Target (Decided 3): on `fra`, adjusted beats set grade by 2 percentage points of mean overlap or more.
