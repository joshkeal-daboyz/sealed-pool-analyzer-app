# SPA-049: Catch lowercase "add" mana and close SPA-042's test gaps

**Goal.** Follow-ups from SPA-042's testers (G-005 deliverable 1, criterion 5). The MANA rule reads only a capital `Add`. Dal R'El, Augment Orphan (trk 231) says "Whenever a land you control enters, add {R} or {G}." mid-sentence, so it is missed. The Inspector also found one hollow assertion and four untested rule boundaries.

## Background the Developer needs

- Read SPA-042 (its rules, change note and History) and G-005's Constraints.
- **The change.** An `Add` clause starts at the word `add` in any case, at a word boundary. Nothing else in the MANA rule changes. Scripted on 2026-11-05 over the five caches (scratchpad `tools/fixing.js` with the case change): the only card whose class changes is Dal R'El, Augment Orphan, which becomes MANA RG. The other lowercase clauses are single-colour or `{R}{R}` and stay not fixing: Glóin the Mighty, Pyre Rhymer, Gardenize, Koth, the Geomancer, Exploratory Mission, Jadzia Dax, Living Legacy.
- Work on a local branch named exactly `SPA-049`. One Developer at a time. Never rewrite a pushed branch; keep scratch files out of the repository. JDK: README, Toolchain section.

## Acceptance criteria

1. A hand-built test pins lowercase `add {R} or {G}` mid-sentence as MANA RG, and lowercase `add {R}{R}` as not fixing.
2. `spa fixing --set trk` ends `40 fixing cards: CYCLING 5, MANA 24, SEARCH 5, TREASURE 6` and lists `Dal R'El, Augment Orphan  MANA  RG`. The `msh`, `hob` and `fra` lines are unchanged.
3. `spa fixing fixtures/pools/trk-manabox-01.csv --set trk` adds `1 Dal R'El, Augment Orphan` (MANA RG) to SPA-042's nine cards and ends `13 fixing copies: W 10, U 9, B 11, R 10, G 10`.
4. The hollow check is fixed: the Carnivorous Cultivator assertion uses the name as printed, `Carnivorous Cultivator // Enroot`, and fails when the graveyard exclusion is removed.
5. Hand-built tests pin the four boundaries the Inspector's probes found untested:
   - a MANA clause stops at the period, so `Add {R}. ... {G}` is not fixing;
   - a SEARCH clause stops at the period, so `Search your library for a card. ... land card` is not SEARCH;
   - a TREASURE match stays within one sentence, so `Create a token. Sacrifice a Treasure` is not TREASURE;
   - a two-faced card whose front face matches and whose back face does not keeps its kind.
6. The gate is green. `git diff <G-005 start> -- core/src/main fixtures/golden` lists no file.
