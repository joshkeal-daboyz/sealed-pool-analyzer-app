# SPA-029: Add the agent module, the grade model, and a replayable model client

**Goal.** G-003 deliverables 1 and 2, and criteria 1 to 3: the `agent` module (the only module that may call a model), the `CardGrade` model and its grade file format, and a model-client seam whose tests replay recorded responses so the gate never calls the API.

## Acceptance criteria

1. `./gradlew :agent:test` runs, and the gate covers the module: format, lint, unit tests, and coverage (a deliberately uncovered scratch function in `agent/src/main` lowers the coverage the gate reports for the ticket, and is removed afterwards).
2. `./gradlew :core:dependencies --configuration runtimeClasspath` lists no `com.anthropic` and no HTTP client; `git diff 06c306c -- core/src/main fixtures/golden` lists no file.
3. `CardGrade` holds `score` (0.0 to 5.0 in steps of 0.5), `confidence` (0.0 to 1.0), `source` (`WIN_RATE` or `MODEL`) and `provenance` (a non-blank string). Constructing one with a score off the scale (5.5, 2.3, -0.5), a confidence outside [0, 1], or a blank provenance throws `IllegalArgumentException` naming the field.
4. A grade file (one per set: header with `setCode`, `source`, `provenance`, `createdAt`; a list of `{ name, collectorNumber, setCode, score, confidence }`) round-trips through write and load unchanged. Loading a file that breaks the schema (an unknown field, a score of 6, a duplicate card) throws an exception listing each problem with a JSON pointer.
5. `GradeLookup.grade(card, setCode)` returns the `WIN_RATE` grade when one exists for the card, else the `MODEL` grade, else null. A test covers all three cases and a card graded in a companion set.
6. A `ModelClient` interface sits between grading code and the SDK. `ReplayModelClient` answers from recorded request and response JSON under `agent/src/test/resources/`, and fails the test, naming the request, if code sends a request it has no recording for. `AnthropicModelClient` wraps the SDK.
7. `ApiKey.require()` returns normally when `ANTHROPIC_API_KEY` is set and non-blank, and otherwise throws an exception whose message is exactly `ANTHROPIC_API_KEY is not set` (the CLI later prints it as one line). Tested with an injected environment map, never the real environment.
8. The gate is green.

## Change note

- New `agent` module (`spa.agent`): `ApiKey`, `CardGrade`/`GradeSource`, the grade file (`GradeFile`, `GradeFiles` load/parse/write, `grades.schema.json`; a nested `header` object plus `grades`), `GradeLookup`, and the `ModelClient` seam with `ReplayModelClient` and `AnthropicModelClient` (SDK 3.0.0, built with `AnthropicOkHttpClient.builder().apiKey(ApiKey.require(env))`). `Coverage.MAIN_SOURCES` gains `agent/src/main/kotlin/`, with a `CoverageTest` case. `agent` also uses the existing catalog entry `json-schema-validator`, as `core` does; no new coordinate besides the SDK.
- `ModelRequest` is deliberately small (model, max tokens, one system prompt, one user turn), with no effort, structured output or batch fields; SPA-033 extends it and its recordings. The two replay recordings are hand-written, not captured from a live call (no key on this PC). `AnthropicModelClient.send` is the one line that is never unit-tested: it needs the network. Its two mapping functions are tested on SDK objects built in memory.
- `ApiKey.require(environment)` takes the environment map with no default, so no line reads the real environment in a test; `AnthropicModelClient.fromEnvironment()` is the one place that defaults to `System.getenv()`. The CLI in a later ticket calls one of those two.
- `GradeLookup` matches a printing by set and collector number, then by card name, so another printing of a graded card (a showcase) finds the grade. A companion card is graded in the main set's file, under its own `setCode`.
- Validator quirk for the next ticket: optimumcode's `multipleOf: 0.5` rejects a whole number written as an integer (`3`), so the schema applies `multipleOf` only to non-integers (`if`/`else`). The writer always writes `3.0`. A duplicate card is checked in code, since the schema cannot express it.
- `pipeline/gate/README.md` still says coverage covers `core` and `cli` (and `app`); it is outside this ticket's scope, so I left it alone.
