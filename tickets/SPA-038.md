# SPA-038: Adjust grades for a pool and print them with reasons

**Goal.** G-004 layer 3, deliverable 3 and criterion 5: `spa pool-grades <pool-file> --set <code> [--pair <XY>]`.

The Architect completes this ticket's Background (the exact rules, the weight file format, and pinned hand-worked pools computed by script) before dispatch, after SPA-035 merges, so the rules use SPA-035's real theme counts. Outline:

- For a colour pair, a card's adjusted grade = set grade + synergy + curve + colour depth, the total capped at plus or minus 1.0 (Decided 6), rounded to 0.5 for display with the unrounded value kept.
- Synergy: from the pool's other cards in the pair's colours that share the card's themes (has or refers), compared with the count expected in a typical pool of the set.
- Curve: the pair's count at the card's mana value against the set baseline's typical curve.
- Colour depth: the pair's playable depth in the card's colours against the baseline.
- Weights live in a committed file (`fixtures/weights/default.json`), so SPA-039 can tune them without a code change.
- Each nonzero adjustment prints a reason line.
