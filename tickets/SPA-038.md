# SPA-038: Adjust grades for a pool and print them with reasons

**Goal.** G-004 layer 3, deliverable 3 and criterion 5: `spa pool-grades <pool-file> --set <code> [--pair <XY>] [--grades <file>] [--weights <file>]`, which moves each card's set grade up or down for one pool and one colour pair, by deterministic rules, and prints the reason for every move. No model call.

## Scope

- Files or modules expected to change:
  - `agent/src/main/kotlin/spa/agent/poolgrade/**` and tests (new)
  - `cli/src/main/kotlin/spa/cli/`: the `pool-grades` command, wired in `Main.kt` and its help text, with tests
  - `fixtures/weights/default.json` and `fixtures/weights/README.md` (new)
  - `README.md`: the command
- Not in scope:
  - `core` (use `PoolParser`, `MetricEngine`, `Baseline` and `CardIndex` as they are). Tuning the weights (SPA-039). Any grade file. Any model call.

  - (none)

## Background the Developer needs

- Read G-004 (layer 3, deliverable 3, criterion 5, Decided 6) and the Change notes of SPA-035 (themes) and SPA-041 (baselines).
- **Set grade** of a card: from `--grades <file>` if given; otherwise `fixtures/grades/<code>.v2.json` if it exists, else `<code>.json`; looked up by the graded printing (set code and collector number), falling back to the card's name, as `GradeLookup` does. A win-rate file is not used here.
- **Candidates for a pair** are the pool's nonland copies whose colours are a subset of the pair's (colourless included): the same cards `MetricEngine` counts in that pair. Copies count separately.
- **Weights** come from `fixtures/weights/default.json` (or `--weights`): `{ "synergy": 0.5, "curve": 0.25, "colour": 0.25, "cap": 1.0 }`.
- **Synergy** (SPA-035's themes and roles, as `ThemeIndex` computes them):
  - A pool copy p is a *partner* of card c when c **refers to** a theme that p **has**, or c **has** a theme that p **has or refers to**.
  - `n` = the number of candidate copies, other than one copy of c itself, that are partners of c.
  - `q` = among the set's sealed-pool cards (SPA-033's pool) whose colours fit the pair and that are not lands, excluding c itself, the share that are partners of c.
  - `e` = `q` × (the number of candidates − 1).
  - synergy = `weights.synergy` × clamp((`n` − `e`) / max(`e`, 1), −1, 1); 0 if c has no theme.
- **Curve**: `b` = the card's mana value bucket (0 to 6, 7 or more). `k` = the pair's creatures plus noncreatures in bucket `b` from `MetricEngine` for this pool; `m` = the baseline means of `/pairs/<pair>/curve/buckets/<b>/creatures` plus `.../noncreatures`. curve = `weights.curve` × clamp((`m` − `k`) / max(`m`, 1), −1, 1). A short bucket raises the card; a crowded one lowers it.
- **Colour depth**: for each of the card's colours x, `r(x)` = (this pool's `/byColor/<x>/playables/total` − the baseline mean of the same) / max(that mean, 1). colour = `weights.colour` × clamp(min over the card's colours of `r(x)`, −1, 1); 0 for a colourless card.
- **Adjusted grade** = clamp(set grade + clamp(synergy + curve + colour, −cap, cap), 0, 5). Keep the unrounded value; show it to two decimals and as the letter of the nearest 0.5 (the letter table in SPA-034's History).
- **Output**: for each pair (all ten in the order of the mean adjusted grade of their top 23 candidate copies, highest first; or the one `--pair` names, in either letter order), a heading line with the pair and that mean, then one line per distinct candidate card, highest adjusted first: adjusted, letter, set grade, change, quantity, name; then one indented reason line per nonzero part, for example `synergy +0.16: 8 partners in the pool, 6.07 expected (Station, Spacecraft)`, `curve −0.14: 7 cards at mana value 2, 4.48 typical`, `colour +0.12: Blue playables 18, typical ...`. Exit 0. Unknown set, unreadable pool or bad weights file: one line, exit 1.
- Work on a local branch named exactly `SPA-038`. One Developer at a time. Never rewrite a pushed branch; keep scratch files out of the repository.

## Acceptance criteria

1. Hand-built tests pin each rule alone and together: synergy for a payoff with and without partners (has and refers, a second copy counted), a card with no theme (0), the `max(e, 1)` floor and the clamp; curve for a short, an even and a crowded bucket, and the 7-or-more bucket; colour for a mono, a gold (minimum of its colours) and a colourless card; the cap; and the 0 to 5 clamp.
2. On `fixtures/pools/trk-manabox-01.csv`, pair WU, with `trk.v2.json` and the default weights, these equal an independent script's values to 3 decimals (G-004 Architect notes, scratchpad `tools/poolgrades.js`): 24 distinct candidates from 33 copies; Enterprise NX-01 (trk/58): set 3.5, synergy +0.159 (n 8, e 6.069), curve −0.141 (k 7, m 4.478), colour +0.117, adjusted 3.635; Type-2 Phaser (trk/271): set 2.5, synergy −0.500 (n 0, e 1.655), curve −0.170 (k 16, m 9.517), colour 0, adjusted 1.830; Command Decision (trk/8): set 3.0, synergy 0 (no theme), curve −0.170, colour −0.108, adjusted 2.721. A test pins them.
3. Every printed adjusted grade equals its set grade plus its listed parts, within the cap and the 0 to 5 range, and each nonzero part has a reason line. A test checks this over every line `spa pool-grades fixtures/pools/trk-manabox-01.csv --set trk` prints.
4. `--pair`, `--grades`, `--weights` and the error cases behave as stated. `git diff <G-004 start> -- core/src/main fixtures/golden` lists no file. The gate is green.
